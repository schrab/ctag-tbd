# Sound Processor Plugin System

## Architecture
- Base class: `ctagSoundProcessor.hpp` — `Process()`, `Init()`, `knowYourself()`
- Factory: `ctagSoundProcessorFactory.hpp.in` — auto-generated by CMake
- Arena allocator: `ctagSPAllocator` — deterministic heap, no fragmentation
- Data model: `ctagSPDataModel` — params, CV assignments, presets
- Registry JSON: `/spiffs/data/sp/mui-*.jsn` (UI metadata) and `mp-*.jsn` (presets)
- CMake auto-discovery: globs `ctagSoundProcessor*.cpp` in `components/ctagSoundProcessor/`

## Creating a New Plugin
No manual registration needed. Create exactly 4 files:

| File | Purpose |
|------|---------|
| `components/ctagSoundProcessor/ctagSoundProcessorXxx.hpp` | Header with class, atomic params |
| `components/ctagSoundProcessor/ctagSoundProcessorXxx.cpp` | `Init()`, `Process()`, `knowYourself()` |
| `spiffs_image/data/sp/mui-Xxx.jsn` | UI metadata |
| `spiffs_image/data/sp/mp-Xxx.jsn` | Default presets |

## Base Class Interface
```cpp
struct ProcessData {
    float *buf;    // 32 frames × 2 interleaved [L,R,L,R,...], range -1..+1
    float *cv;     // CV array (N_CVS, 90 on BBA)
    uint8_t *trig; // Trigger array (N_TRIGS, 40 on BBA)
};

class ctagSoundProcessor {
    virtual void Process(const ProcessData &) = 0;
    virtual void Init(std::size_t blockSize, void *blockPtr) = 0;
    virtual ~ctagSoundProcessor() {};
    void* operator new(std::size_t size) { return ctagSPAllocator::Allocate(size); }
protected:
    virtual void knowYourself() = 0;
    bool isStereo = false;
    int const bufSz = 32;
    int processCh = 0;
    // Parameter maps
    map<string, function<void(const int)>> pMapPar;
    map<string, function<void(const int)>> pMapCv;
    map<string, function<void(const int)>> pMapTrig;
};
```

## Factory File Generation
`CMakeLists.txt` in `components/ctagSoundProcessor/`:
- Globs `ctagSoundProcessor*.cpp` files
- Strips `ctagSoundProcessor` prefix to get SP_ID
- Generates `ctagSoundProcessors.hpp` with `#include` directives
- Generates `@BIG_IF@` with `if(type.compare("SP_ID") == 0) processor = new ctagSoundProcessorXxx();`
- Runs `configure_file()` to produce final factory

## Instantiation Flow
```
SetSoundProcessorChannel(chan, "SimpleVCA")
  → ctagSPAllocator::PrepareAllocation(CH0|CH1|STEREO)
  → ctagSoundProcessorFactory::Create("SimpleVCA", CH0)
    → operator new → ctagSPAllocator::Allocate(size)
    → constructor runs
    → processor->Init(remainingSize, remainingPtr)
      → knowYourself() (register params, set id, isStereo)
      → model = make_unique<ctagSPDataModel>(id, isStereo)
      → LoadPreset(0)
    → SetProcessChannel(ch)
```

## Memory Model
The arena allocator splits memory:
- `CH0` — half the buffer
- `CH1` — other half
- `STEREO` — full buffer

`Init()` receives `blockSize` (remaining bytes) and `blockPtr` (ptr to remaining memory) for plugin's internal allocations (e.g., wavetables).
