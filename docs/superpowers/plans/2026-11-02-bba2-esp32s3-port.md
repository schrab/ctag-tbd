# BBA v2 (ESP32-S3) Port — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a new firmware platform `TBD_PLATFORM_BBA2` (custom ESP32-S3-WROOM-1 N16R8 board, WM8978 codec) running single-core synthesis at a locked 44.1 kHz, with the second-core helper tasks compiled out and a load-time CPU-budget cap.

**Architecture:** New Kconfig platform + `sdkconfig.defaults.bba2` beside the existing ones; new `wm8978` I2C driver class + `codec_bba2` facade implementing the existing `DRIVERS::Codec` interface; Elements/Mbeads helper paths `#if`-guarded off for BBA2 only; a host-tested pure budget-cap helper drives Elements' load-time resolution. Legacy targets are untouched.

**Tech Stack:** ESP-IDF 6.1 (this branch's toolchain), C++17/20, `driver/i2s_std.h`, `esp_driver_i2c`, FreeRTOS. Host tests: plain g++ via `tests/host/run_tests.sh`.

**Spec:** `doc/bba2-esp32s3-sdd.md` — read it first; every section reference below (§n) points there.

## Global Constraints

- ESP-IDF 6.1: `source /home/ubuntu/esp-idf/export.sh` (WSL; Omarchy: `/home/schrab/esp/esp-idf-v5.5.4/export.sh` — same repo, this plan was written on WSL).
- All BBA2 source-level guards use `CONFIG_TBD_PLATFORM_BBA2` (real Kconfig symbol from `sdkconfig.h`). Task 3 also defines the **alias** `-DCONFIG_TBD_PLATFORM_BBA=1` (CMake compile definition only) so the 21 existing `#ifdef CONFIG_TBD_PLATFORM_BBA` guards in `main/` take the BBA arm. Where both could match, check `CONFIG_TBD_PLATFORM_BBA2` **first**.
- Legacy targets (BBA/A1S, MK2, …) must keep compiling and behaving unchanged: no behavior edit may be visible outside a `#if defined(CONFIG_TBD_PLATFORM_BBA2)` guard (or a new file).
- BBA2 pins (spec §3): I2S MCLK=2, BCLK=41, WS=42, DACDAT=40, ADCDAT=39; I2C SDA=8, SCL=9; SDMMC CLK=6, CMD=7, D0=10, D1=11, D2=12, D3=13; link UART1 TX=17, RX=18. GPIO 0/3/45/46 (strapping), 19/20 (USB), 35–37 (OPI PSRAM) never used.
- WM8978: I2C 7-bit address **0x1A**, write-only protocol (9-bit value: byte0 = `(reg<<1)|bit8`, byte1 = `val&0xFF`), shadow register file in RAM. MCLK from S3 at 256·fs.
- I2S: master, 16-bit stereo Philips, `dma_desc_num=4`, `dma_frame_num=32` (never grow `dma_desc_num`), `mclk_multiple = 256`, sample rate locked **44100** on BBA2.
- Budget cap: cap threshold = **90% of 174,150 cycles = 156,735**; only Elements loads are capped (52→32→24→16); non-Elements over-cap loads are allowed with a logged warning.
- Never edit files with inline python/sed scripts — use Read/Edit/Write tools (AGENTS.md working rule).
- FreeRTOS tick on BBA2 is 1000 Hz (`CONFIG_FREERTOS_HZ=1000`).

## Review Focus

1. **Mono mic → stereo frame duplication**: in mic input mode the WM8978 captures only the left ADC; `ReadBuffer` must duplicate left→right so the MIX-page IN meter and any plugin see signal on both channels. (Pinned by Task 4 Step 1 — code review gate, no host test possible.)
2. **Over-cap non-Elements chain** (e.g. TBDaits+TBDings+Claude = 162k > 156,735): the load must be **allowed** with a warning log, never refused and never silently dropped. (Pinned by Task 2 test `NonElementsOverCapIsAllowed`.)
3. **Cap evaluation timing**: the cap is computed at Elements *load* time from the *other* channel's currently active plugin; reloading Elements re-evaluates. No live re-rating after load. (Pinned by Task 2 test ordering cases.)
4. **SD absent at boot**: `InitSD` mount failure must leave `IsSDPresent()==false`/`IsSDMounted()==false` and the C3 MOUNT command re-attempt cleanly — no CD pin, mount-state only. (Pinned by Task 8 code review against `fs.cpp` failure paths.)
5. **Alias define discipline**: any future `#ifdef CONFIG_TBD_PLATFORM_BBA` added to shared code silently applies to BBA2. New platform-divergent code must use `CONFIG_TBD_PLATFORM_BBA2`. (Pinned by Task 3 comment block and Task 11 AGENTS.md entry.)

```cpp
#pragma once

// BBA2 (ESP32-S3) load-time CPU budget (SDD §6.3).
//
// The S3 audio task is single-core (no Elements helper task): every loaded
// plugin draws from one 174,150-cycle budget per 32-sample block at 44.1 kHz
// (doc/esp32s3-porting-guide.md). This helper is the ONLY component that
// decides plugin load de-rating; it is pure and host-tested
// (tests/host/test_chain_budget.cpp).
//
// Policy: only an Elements LOAD is ever capped (52 -> 32 -> 24 -> 16 modes,
// largest step whose block sum fits under 90% of budget). Any other
// over-cap load combination is allowed with a warning — operators choose,
// SPManager logs. Estimates below are bench-measured (guide §6.1) except
// Elements 24M/16M, which are linear interpolations of the 12/32/52/56M
// measurements (~51.7k base + ~1.27k/mode).

#include <atomic>
#include <cstdint>

namespace CTAG {
    namespace SP {

        struct ChainBudget {
            static constexpr uint32_t kBudgetCycles = 174150; // 32/44100 * 240 MHz
            static constexpr uint32_t kCapPct = 90;
            static constexpr uint32_t kCapCycles = kBudgetCycles * kCapPct / 100; // 156735

            // Estimated cycles/block at 44.1 kHz. Unknown ids cost 0 (not
            // counted — logged by the caller, never refused).
            static uint32_t EstimateCycles(const char *id) {
                if (id == nullptr) return 0;
                const auto eq = [](const char *a, const char *b) {
                    while (*a && *b && *a == *b) { ++a; ++b; }
                    return *a == *b;
                };
                if (eq(id, "Void") || eq(id, "")) return 0;
                if (eq(id, "TBDaits")) return 45000;
                if (eq(id, "TBDings")) return 55000;
                if (eq(id, "Claude")) return 62000;
                if (eq(id, "Mbeads")) return 100000; // provisional, unmeasured (SDD §6.3)
                if (eq(id, "Elements")) return 120000; // 52 modes
                return 0;
            }

            // Resolution ladder for Elements loads. Costs parallel the steps.
            // Returns the chosen resolution and stores it into
            // gElementsCapResolution. Non-Elements loads return the current
            // cap untouched.
            static int ElementsResolution(const char *newId, const char *otherId) {
                if (newId == nullptr || !eq_id(newId, "Elements")) {
                    return gElementsCapResolution.load(std::memory_order_relaxed);
                }
                static constexpr int kSteps[] = {52, 32, 24, 16};
                static constexpr uint32_t kStepCosts[] = {120000, 93000, 82000, 72000};
                const uint32_t other = EstimateCycles(otherId);
                for (std::size_t i = 0; i < 4; ++i) {
                    if (other + kStepCosts[i] <= kCapCycles) {
                        gElementsCapResolution.store(kSteps[i], std::memory_order_relaxed);
                        return kSteps[i];
                    }
                }
                // Even 16 modes overflows next to 'other' — best effort floor.
                gElementsCapResolution.store(16, std::memory_order_relaxed);
                return 16;
            }

        private:
            static bool eq_id(const char *a, const char *b) {
                while (*a && *b && *a == *b) { ++a; ++b; }
                return *a == *b;
            }
        };

        // Consumed by ctagSoundProcessorElements::init() on BBA2; SPManager
        // writes it through ChainBudget::ElementsResolution before Create.
        // Legacy targets never read it.
        inline std::atomic<int> gElementsCapResolution{52};

    } // namespace SP
} // namespace CTAG
```

```cpp
#pragma once

// WM8978 codec control driver for BBA2 (SDD §5.1).
//
// 2-wire (I2C) control at 7-bit address 0x1A. The WM8978 register interface
// is WRITE-ONLY over I2C: every register is 9 bits, transmitted as
//   byte0 = (reg << 1) | ((val >> 8) & 1)
//   byte1 = val & 0xFF
// so the driver keeps a 58-entry shadow file; reads come from RAM only.
// Register map/power sequence ported from the legacy in-repo SPI driver
// (components/drivers/codec.cpp WM8978_* helpers, register-for-register).
//
// Board facts (SDD §2): no shutdown/enable pin (power = R1-R3 registers),
// stereo line in on L2/R2, mono mic on LIP/LIN via the input PGA,
// stereo line out on OUT1 (R52/53), mono speaker = OUT2 bridged (R43 bit4
// INVROUT2 + R54/55 volumes).

#include <stdint.h>

class wm8978 final {
private:
    uint16_t _regs[58]; // shadow register file (write-only bus)
    bool write_reg(uint8_t reg, uint16_t val);
    static bool ensure_bus();

public:
    // OUT1 (headphone/line) volume registers top out at 63; 0 dB = 57.
    // Codec::MAX_OUTPUT_LEVEL resolves to 63 on BBA2 via codec.hpp's
    // non-ES8388 branch, so keep the ceiling identical.
    static constexpr uint8_t OUTPUT_VOLUME_MAX = 63;
    static constexpr uint8_t OUTPUT_VOLUME_0DB = 57;

    enum class Input : uint8_t { LINE = 0, MIC = 1 };

    wm8978() { for (auto &r : _regs) r = 0; }
    ~wm8978() = default;

    bool init();        // full power-up + path bring-up, line in default
    bool identify();    // ACK on the R0 soft-reset write
    uint16_t *readAllReg() { return _regs; }
    bool debugReadReg(uint8_t reg, uint16_t &val) {
        if (reg > 57) return false;
        val = _regs[reg];
        return true;
    }

    bool setOutputVolume(uint8_t lvol, uint8_t rvol); // OUT1 0..63, 0 mutes
    bool setSpkVolume(uint8_t vol);                   // OUT2 bridge 0..63, 0 mutes
    bool inputSelect(Input sel);                      // swaps L2/R2 <-> PGA path
    bool setInputGain(uint8_t gain);                  // mic PGA 0..63 (-12..+35.25 dB)
    bool setMicBoost(bool on);                        // PGA input boost x5 (+20 dB... R47/48 bit8)
    bool softMute(bool mute);                         // R5 DAC soft mute
    bool highPass(bool on);                           // R14 ADC HPF
    bool writeReg(uint8_t reg, uint16_t val);         // raw shadowed write (facade bypass paths)
};
```

- [ ] **Step 2: Write `wm8978.cpp`**

```cpp
#include "wm8978.hpp"

#include "driver/i2c_master.h"
#include "esp_log.h"

// BBA2 I2C pins (SDD §3). Same compile-time-constant pattern as es8388.cpp.
static constexpr int WM8978_SDA_PIN = 8;
static constexpr int WM8978_SCL_PIN = 9;
static constexpr uint8_t WM8978_I2C_ADDR = 0x1A; // 7-bit, 2-wire mode
static constexpr uint32_t WM8978_I2C_SPEED_HZ = 400000;

static i2c_master_bus_handle_t s_bus = nullptr;
static i2c_master_dev_handle_t s_dev = nullptr;
static const char *TAG = "WM8978";

bool wm8978::ensure_bus() {
    if (s_bus != nullptr && s_dev != nullptr) return true;
    i2c_master_bus_config_t cfg = {};
    cfg.i2c_port = -1; // auto-select, same strategy as es8388.cpp
    cfg.sda_io_num = (gpio_num_t)WM8978_SDA_PIN;
    cfg.scl_io_num = (gpio_num_t)WM8978_SCL_PIN;
    cfg.sda_pullup_en = GPIO_PULLUP_ENABLE;
    cfg.scl_pullup_en = GPIO_PULLUP_ENABLE;
    cfg.clk_flags = I2C_CLK_FLAGS_DEFAULT; // 400 kHz capable
    if (i2c_new_master_bus(&cfg, &s_bus) != ESP_OK) {
        ESP_LOGE(TAG, "i2c bus init failed");
        return false;
    }
    i2c_device_config_t dev = {};
    dev.dev_addr_length = I2C_ADDR_BIT_LEN_7;
    dev.device_address = WM8978_I2C_ADDR;
    dev.scl_speed_hz = WM8978_I2C_SPEED_HZ;
    if (i2c_master_bus_add_device(s_bus, &dev, &s_dev) != ESP_OK) {
        ESP_LOGE(TAG, "i2c device add failed");
        return false;
    }
    return true;
}

bool wm8978::write_reg(uint8_t reg, uint16_t val) {
    if (reg > 57) return false;
    if (!ensure_bus()) return false;
    uint8_t buf[2] = {
        (uint8_t)((reg << 1) | ((val >> 8) & 0x01)),
        (uint8_t)(val & 0xFF),
    };
    // Bounded retries: control calls can originate off the audio task while
    // the bus is busy (same reasoning as es8388.cpp).
    for (int attempt = 0; attempt < 3; ++attempt) {
        if (i2c_master_transmit(s_dev, buf, sizeof(buf), 100 /*ms*/) == ESP_OK) {
            _regs[reg] = val & 0x1FF; // 9-bit registers
            return true;
        }
        esp_rom_delay_us(1000);
    }
    ESP_LOGW(TAG, "write R%u=0x%03X failed", reg, val);
    return false;
}

bool wm8978::identify() {
    if (!ensure_bus()) return false;
    // R0 write = soft reset; an ACK is the only presence probe the
    // write-only interface offers.
    return write_reg(0, 0);
}

bool wm8978::init() {
    if (!identify()) {
        ESP_LOGE(TAG, "no ACK on reset write — codec missing?");
        return false;
    }

    // Power-up + path bring-up. Values ported from the legacy
    // components/drivers/codec.cpp WM8978_Init / helpers.
    write_reg(1, 0x00F);   // R1: BUFIOEN, VMIDSEL=11, BIASEN
    write_reg(2, 0x1BF);   // R2: ROUT1/LOUT1 en, BOOST en, ADC en, PGA en
    write_reg(3, 0x00F);   // R3: LMIX/RMIX en, LOUT2/ROUT2 (speaker) en
    write_reg(4, 0x010);   // R4: I2S format (fmt=2 <<3), 16-bit, slave
    write_reg(6, 0x000);   // R6: MCLK direct from S3, no PLL, no divide
    write_reg(10, 0x008);  // R10: DAC OSR 128x, soft mute off
    write_reg(14, 0x108);  // R14: ADC OSR 128x, HPF on
    write_reg(43, 0x010);  // R43: INVROUT2 — bridge OUT2 for the mono speaker
    write_reg(49, 0x002);  // R49: thermal shutdown on
    write_reg(50, 0x001);  // R50/51: L/R output mixer = DAC, no bypass
    write_reg(51, 0x001);

    // Default paths: line in (L2/R2, 0 dB), OUT1 at 0 dB, speaker at 0 dB.
    inputSelect(Input::LINE);
    setOutputVolume(OUTPUT_VOLUME_0DB, OUTPUT_VOLUME_0DB);
    setSpkVolume(OUTPUT_VOLUME_0DB);
    ESP_LOGI(TAG, "WM8978 ready (line in, OUT1+OUT2 at 0 dB)");
    return true;
}

bool wm8978::setOutputVolume(uint8_t lvol, uint8_t rvol) {
    lvol &= 0x3F;
    rvol &= 0x3F;
    if (lvol == 0) lvol |= 0x40; // 0 = mute (HPZC muted path)
    if (rvol == 0) rvol |= 0x40;
    const bool ok = write_reg(52, lvol);
    // R53 bit8 (HPVU) latches both channels simultaneously.
    return write_reg(53, rvol | 0x100) && ok;
}

bool wm8978::setSpkVolume(uint8_t vol) {
    vol &= 0x3F;
    if (vol == 0) vol |= 0x40;
    const bool ok = write_reg(54, vol);
    return write_reg(55, vol | 0x100) && ok; // SPKVU latch
}

bool wm8978::inputSelect(Input sel) {
    // R47/48: bits[6:4] = L2/R2 -> boost (line in), bit8 = PGA input boost,
    //         bits[2:0] = AUXL/AUXR (unused on BBA2).
    // R44:    bits 0/4 = LIP/LIN -> PGA, bits 1/5 = RIN/RIN2 -> PGA (mic).
    // R2:     bits 3:2 = INPPGAENR/L.
    uint16_t r47 = _regs[47] & 0x0F3; // clear line-in nibble + boost bit
    uint16_t r48 = _regs[48] & 0x0F3;
    uint16_t r44 = _regs[44] & ~0x33;
    uint16_t r2 = _regs[2] & ~0x00C;
    if (sel == Input::LINE) {
        // Line in: L2/R2 at 0 dB (gain 5 = 0 dB per legacy LINEIN_Gain).
        r47 |= (5 << 4);
        r48 |= (5 << 4);
    } else {
        // Mic: LIP/LIN into the PGA, PGA enabled, boost on (mono mic needs it).
        r44 |= 0x11; // LIP2INPPGA | RIP2INPPGA (bits 4 and 0)
        r2 |= 0x00C; // both PGAs enabled
        r47 |= 0x100;
        r48 |= 0x100;
        setInputGain(40); // sane default ~+18 dB, MIX page adjusts from here
    }
    bool ok = write_reg(44, r44);
    ok = write_reg(2, r2) && ok;
    ok = write_reg(47, r47) && ok;
    return write_reg(48, r48) && ok;
}

bool wm8978::setInputGain(uint8_t gain) {
    gain &= 0x3F;
    const bool ok = write_reg(45, gain);             // LPGA
    return write_reg(46, gain | 0x100) && ok;        // RPGA + update latch
}

bool wm8978::setMicBoost(bool on) {
    uint16_t r47 = _regs[47], r48 = _regs[48];
    if (on) { r47 |= 0x100; r48 |= 0x100; }
    else    { r47 &= ~0x100; r48 &= ~0x100; }
    const bool ok = write_reg(47, r47);
    return write_reg(48, r48) && ok;
}

bool wm8978::softMute(bool mute) {
    uint16_t r5 = _regs[5] & ~0x001;
    if (mute) r5 |= 0x001;
    return write_reg(5, r5);
}

bool wm8978::highPass(bool on) {
    uint16_t r14 = (_regs[14] & ~0x001) | (on ? 0x001 : 0);
    return write_reg(14, r14);
}

bool wm8978::writeReg(uint8_t reg, uint16_t val) {
    return write_reg(reg, val);
}
```

```cpp
void Codec::ReadBuffer(float *buf, uint32_t sz) {
    // sz = frames (BUF_SZ=32); 16-bit stereo.
    static int16_t raw[32 * 2];
    const size_t bytes = sz * 2 * sizeof(int16_t);
    size_t bytes_read = 0;
    if (i2s_channel_read(s_rx, raw, bytes, &bytes_read, pdMS_TO_TICKS(100)) != ESP_OK ||
        bytes_read != bytes) {
        // Zero-fill on error/timeout — the audio task must never block
        // forever on a dead bus (A1S semantics, SDD §5.2).
        for (uint32_t i = 0; i < 2 * sz; ++i) buf[i] = 0.0f;
        return;
    }
    constexpr float kScale = 3.0518509476E-5f; // 1/32767
    for (uint32_t i = 0; i < sz; ++i) {
        const float l = raw[2 * i] * kScale;
        const float r = raw[2 * i + 1] * kScale;
        if (s_mic_mode) {
            // Mono mic: only the left ADC carries signal (LIP/LIN); duplicate
            // so meters and plugins see a centered stereo image (Review Focus 1).
            buf[2 * i] = l;
            buf[2 * i + 1] = l;
        } else {
            buf[2 * i] = l;
            buf[2 * i + 1] = r;
        }
    }
}

void Codec::WriteBuffer(float *buf, uint32_t sz) {
    static int16_t raw[32 * 2];
    for (uint32_t i = 0; i < 2 * sz; ++i) {
        float v = buf[i];
        if (v > 1.0f) v = 1.0f;
        if (v < -1.0f) v = -1.0f;
        raw[i] = (int16_t)(v * 32767.0f);
    }
    i2s_channel_write(s_tx, raw, sz * 2 * sizeof(int16_t), nullptr, pdMS_TO_TICKS(100));
}
```
