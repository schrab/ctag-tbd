# Vendored Rubato plaits tree (namespace `rplaits`)

This directory is a **vendored, transformed copy** of the `plaits/` subtree from
the Rubato Audio eurorack fork (https://github.com/lylepmills/eurorack,
"Plaits Lab / Plaits Palette", Plaits 1.2 based). The user's working clone
lives at `components/rubato` (gitignored — it also contains ~150 MB of
unrelated module trees and build artifacts); this vendored copy is what the
firmware actually builds against, so upstream updates never change our build
silently. Re-vendor by re-copying and re-applying the transformations below.

Catalog of record: `alt_firmwares/plaits_lab_catalog/catalog.json` (vendored
copy). It is the source for `rplaits/dsp/engine_config.h`, generated by
`tools/tbpalette/gen_engine_config.py` — **do not hand-edit** that header.

## Why a second plaits tree

The eurorack submodule's own plaits tree (`components/mutable/eurorack/plaits`,
namespace `plaits`) must stay untouched: TBDaits, WTOsc, WTOscDuo, Retroactor,
Freakwaves and friends compile against it and their sound/presets must not
change. Two unrenamed trees cannot link (duplicate `plaits::` symbols), so the
vendored Rubato tree is namespaced `rplaits` and the two trees coexist.

## Transformations applied to the upstream `plaits/` subtree

Mechanical, verified by the host coexistence smoke test (see
`doc/tbpalette-plan.md` Phase 1 / `tests/host`):

1. **Namespace rename**: `namespace plaits` → `namespace rplaits`,
   `plaits::` → `rplaits::` (all `.h`/`.cc`).
2. **Include-path rename**: the directory is `rplaits/` and all internal
   `#include "plaits/..."` became `#include "rplaits/..."`, so the two trees
   have disjoint include prefixes and no `-I` ordering can ever mix them.
3. **Include-guard rename**: `PLAITS_*_H_` guards became `RPLAITS_*_H_`
   (upstream guards are identical to the eurorack tree's and would suppress
   headers).
4. **Clock retune** (`rplaits/dsp/dsp.h`): 44.1 kHz (kSampleRate =
   kCorrectedSampleRate = 44100 → zero pitch offset) and 32-sample blocks
   (kMaxBlockSize = kBlockSize = 32) to match the BBA codec task.
5. **Engine-count ceiling** (`rplaits/build_config.h`): 32 → 128
   (upstream's ceiling came from uint32 bit masks; see next item).
6. **uint64 behavior masks** (`rplaits/dsp/voice.cc`): `1u << engine_index`
   → `1ull << engine_index` (13 sites).
7. **Engine config**: `rplaits/dsp/engine_config.h` — generated, 98 engines in
   catalog order (= TBPalette `smodel` index), uint64 speech/lpc/natural/
   chiptune masks, six-op placements 22/23/24 → DX7 syx banks 0/1/2.

## What was NOT needed

- The `stmlib` submodule is absent upstream (uninitialized); the tree compiles
  against the eurorack submodule's stmlib (same MI lineage).
- No engine needed exclusion: lpc-speech's word banks are baked in
  `lpc_speech_synth_words.cc`, natural-speech reads its baked
  `natural_speech_data.h`, formant-speech never dereferences a word bank.
- `plaits/bootloader`, `plaits/drivers`, `plaits/tools`, `plaits/test`,
  `plaits/hardware_design` and the makefiles are not vendored (not compiled;
  `stm_audio_bootloader` deps live only in uncompiled files).

## RAM facts (host-measured, layout-identical on Xtensa)

- `sizeof(rplaits::Voice)` with all 98 engines: **23,024 B**.
- Largest single engine: `SixOpEngine` 2,088 B; sum of all 98: 25,888 B.
- Scratch: TBPalette passes a 32 KB pool (upstream uses 16 KB); the LPC word
  bank decoder allocates ~14.5 KB from it, the brass/reed-pipe delay lines
  ≤ 10.8 KB. Object + scratch ≈ 56 KB of the 110,592 B STEREO arena.
